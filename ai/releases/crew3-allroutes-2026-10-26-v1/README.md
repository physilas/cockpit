# Crew 3

Eine sichtbare Version, alle 21 Standardrouten mit 186 erlaubten Kartenfällen.
Entwicklungsvorschau: auch Nullquoten sind auf Nutzerwunsch auswählbar.
Auswahl nach gleichgewichteten Routenmitteln, Grundspielmittel als Tie-Break.
Einzelwerte in development.json; keine unabhängige Qualifikation.
Höhere Crew-Nummer garantiert keine höhere Spielstärke auf jeder Strecke.

Der vorhandene Leck-Stand mit 80.139 damaligen Trainingsentscheidungen wurde unverändert übernommen. Er schlug die Praktikantenvariante im vorher festgelegten breiten Vergleich. Keine neuen Tensoränderungen.
